What it is

Marginalia first, then everything else

Research reading is scattered: PDFs in one folder, highlights trapped inside them, notes in another app, citations in a third, and a Word document that has to pull it all together. The usual tools were built around the library. The thinking happens in the margins.

Ad Marginem starts from the margins. Read a paper, mark it up, write about it, and cite it, without the work ending up in four places. It keeps a full copy of your library on each device, works offline, and syncs when it can.

Why it’s useful

From the PDF to the published paper

  • Annotations that survive

    Highlights, underlines, sticky notes and pencil drawings stay with the paper and come out intact when you export it.

  • A library that fills itself in

    Drop in a PDF or paste a DOI and the title, authors and journal are filled out. The browser extension saves papers from publisher sites in one click.

  • Notes that know your library

    Write in Markdown or rich text, link straight to papers and other notes, and lay out the messier ideas on a whiteboard.

  • Citations without the busywork

    APA, MLA, Chicago, Harvard or IEEE, switchable for a whole document. The Word add-in inserts citations and keeps the bibliography up to date.

How it works

Collect, read, write

  1. 01

    Build the library

    Import PDFs or add papers by DOI, from Shannon in 1948 to last week’s preprint. Sort, filter, tag, and gather them into collections and saved searches.

  2. 02

    Write it down

    Notes sit next to the library, so a question about one paper can link straight to another. Everything stays searchable across the whole collection.

Under the hood

How it’s built

Apps
Tauri and React on the desktop, React Native on iPad, plus a browser extension and a Word add-in
Shared core
One TypeScript codebase for the models, citations and PDF reader, built on PDF.js
Storage
A full SQLite library on every device, with full-text search
Sync
An operation log relayed through Cloudflare Workers, so devices catch up without losing edits
